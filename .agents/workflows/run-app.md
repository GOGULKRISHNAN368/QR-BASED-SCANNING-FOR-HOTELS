---
description: How to run the MenuMagic Dashboard (Frontend & Backend)
---

Follow these steps to start both the backend server and the frontend development server.

1.  **Check Dependencies**: Ensure Node.js is installed.
2.  **Start the Backend**:
    - Run the backend on port 5000.
    - // turbo
    - `npm run start:backend`
3.  **Start the Frontend**:
    - Run the Vite development server on port 8080.
    - // turbo
    - `npm run dev`
4.  **Confirm Connection**: Look for `✅ MongoDB Atlas Connected` in the backend terminal.
5.  **Access the App**: Open [http://localhost:8080](http://localhost:8080) in your browser.
